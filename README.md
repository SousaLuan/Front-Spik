# Front-Spik 🚀

Este é o projeto de Front-end da aplicação SPIK, desenvolvido com foco em performance, tipagem forte e interface amigável.

## 🛠️ Tecnologias
As principais ferramentas utilizadas no desenvolvimento:

- **Framework:** [Next.js](https://nextjs.org/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)

## 📋 Status do Projeto
Atualmente o projeto conta com:
- Fluxo de autenticação (Login e Cadastro).
- Componentes reutilizáveis de interface.
  
## 🔧 Como executar
1. Clone o repositório:
   `git clone https://github.com/SousaLuan/Front-Spik.git`
2. Instale as dependências:
   `npm install`
3. Inicie o servidor:
   `npm run dev`
